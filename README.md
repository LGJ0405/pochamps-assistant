# 포챔스 배틀 어시스턴트 (pochamps-assistant)

포켓몬 챔피언스(포챔스)를 위한 지능형 배틀 어시스턴트 코어 프로젝트입니다.

## 🚀 빠른 시작

### 1. 의존성 설치

#### Node.js
```bash
npm install
```

#### Python
```bash
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Step 1 계산 엔진 테스트
```powershell
# Windows PowerShell
$env:PYTHONIOENCODING = "utf-8"
python test_step1_calc.py
```
